# v0.6.9.3 validation

## Route correction

Home Assistant Core 2026.7.2 registers the generic `app` panel in `homeassistant/components/hassio/__init__.py`. The frontend App panel extracts the slug from `/app/<slug>`. The previous card destination `/hassio/ingress/<slug>` addressed the old panel and could fall back to the default dashboard. Correcting the routing event alone in v0.6.9.2 did not correct that obsolete destination.

The status entity now publishes `/app/<full-slug>`. Card navigation prefers the registered dedicated sidebar path, then falls back to the generic App panel. It translates saved old generic paths based on the registered HA panels. Both local and repository identities are tested across Open map, Status and Settings recovery. Legacy HA and explicit dedicated-sidebar routes have separate checks. The constrained page handoff records the resolved route, not the obsolete configured path.
