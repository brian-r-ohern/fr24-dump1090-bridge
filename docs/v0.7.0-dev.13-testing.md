# v0.7.0-dev.13 theme control

1. Upgrade and hard-refresh once to load the updated toolbar. Find Map theme next to Fit aircraft.
2. Select Light, Dark and Auto. Each change applies immediately without restarting the App or reloading the map; density and aircraft retain their own colors.
3. Keep a selected mode for more than five minutes. Periodic map-config refresh must not reset it to the App default.
4. Select Auto and change browser/device preference; the map follows it. Explicit Light/Dark ignore that preference.
5. Open/reload a map page. It uses the saved App map_theme default. Toolbar changes are local to the open page and do not modify the saved App options.

130 Python tests and shipped JavaScript checks pass, including live selection events, default-refresh override handling and preference changes. Browser visual layout remains a user check.
