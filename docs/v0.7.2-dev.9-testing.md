# v0.7.2-dev.9 testing

Adds destination-relative movement and selected-track filenames to dev.8.
Direction requires at least five observations spanning 60 seconds, using up to
120 seconds of range history. +/-30 kt radial-speed thresholds separate inbound,
crossing (little radial movement), and outbound. This does not describe a filed route.
Sustained movement away requires ten observations spanning 180 seconds, 2 NM
range gain, and increasing range on at least 80% of intervals within 300 seconds.
Established racetrack or repeated-orbit evidence in that window suppresses divergence;
candidates alone do not. Suppression can persist up to five minutes after the last
established observation. Track gaps and destination code changes restart support.
Destination metadata age is explicitly unknown. Ordinary departure vectors may still
meet these experimental thresholds; movement away does not establish diversion.

Selected exports use aircraft-analysis-history-A0785C.geojson.gz when ICAO is
known; local track ID is the fallback. Export all keeps its generic filename.

Validation: 195 Python tests passed before packaging; map script syntax checked.
QGIS display of dev.8 GeoJSON was confirmed by the tester. Dev.9 destination
logic, filenames, and recovery behavior require installation/live checks.
Synthetic pattern and CPA tests do not establish field detection rates.

Suggested checks: selected/export-all filenames; inbound and outbound tracks;
short departure legs; established hold suppression and subsequent exit;
destination metadata age label; popup facet persistence; SBS interruption/recovery.
No container image build or HAOS installation was performed in this environment.
