1. SFDPS direct ETA should now appear with native destination, airport lookup and positive reported GS. It remains direct airport-center distance/current GS, not landing time.
2. Expand Arrival assumptions. It should reflect descent and slowdown and generally exceed the direct estimate.

4. High-altitude/short-distance examples must report extra route distance needed, not produce an impossible numeric modeled arrival. Model range is experimental scenarios; altitude datum/wind/routing are assumptions. Save a few known-arrival examples for later calibration.
5. Verify altitude-coded motion/filter badges and density cache auto loading still work. All algorithms, defaults and limitations are documented in motion-analytics-engineering.md, including selection of reported versus derived speed and the coupled ETA equations.
