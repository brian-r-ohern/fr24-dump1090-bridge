# v0.7.1 release validation

## Scope

v0.7.1 consolidates envelope.1–envelope.4: instrumentation, SQL aggregation, bounded NumPy bearing reduction and saved Load/Build controls. It does not implement repeated single-aircraft geometry; that work is planned for v0.7.2.

## Source and documentation review

- Current App/build/Docker version set to 0.7.1. Dashboard integration remains independently versioned 0.7.0 because its code is unchanged.
- AppArmor explicitly includes density_envelope_batches.py; NumPy is supplied by Alpine py3-numpy.
- Public changelog consolidates envelope development builds into one release entry; detailed diagnostic records remain in docs.
- Readmes and operating/API instructions describe Load/Build, 12-hour recommendation, persistence, invalidation and actual popup-versus-log diagnostics.
- Roadmap shifts repeated geometry to 0.7.2 and subsequent capabilities one increment later.

## Practical limits and release smoke test

Build remains synchronous and can exceed client/proxy timeouts; a disconnected request does not cancel work. Saved Load avoids expensive rebuilding. Temporary snapshot/aggregate disk space remains required. Final v0.7.1 package should be installed/upgraded on HAOS and checked for preserved settings/density history, AppArmor/startup errors, Build, reload/Load, restart/Load and downstream non-FAA feed consumers. Geometry/pattern behavior is unchanged. No GitHub publication is performed by this package preparation.
