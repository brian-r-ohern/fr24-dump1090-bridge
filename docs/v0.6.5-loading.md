The browser restarted its request every 15 seconds, allowing slower requests to be cancelled repeatedly.

Periodic refresh now skips active requests. User selection changes still replace stale requests. A 120-second timeout displays an explicit error. Storage remains zoom 17 and radial coverage remains 0.5 degrees / 720 bins. Full-resolution exports are unchanged.

Collection status includes last_query timing, lock wait, aggregated rows read, cell count and requested/actual grid zoom. Server logs print each completed query. The map reports displayed cells and elapsed time.
